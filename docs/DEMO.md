# Three-minute finalist demo

## Before recording

1. Start Ollama, pull `qwen3-vl:4b-instruct-q4_K_M`, run `npm run director:local:setup`, then
   start the password-protected local Movement Director with `npm run codebuddy:local`. Put the
   printed password in local `.env` as `CODEBUDDY_PASSWORD`, then start MoveRealm. `npm run
   codebuddy` remains available for a signed-in upstream CodeBuddy session.
2. Open `/api/health` and confirm `codeBuddyConnected: true`.
3. Clear a deliberately constrained camera lane with one visible chair or desk edge.
4. Rehearse the guided demo as a backup. Keep the local build and one static deployment open.

## Story beats

1. **Problem, 15 seconds:** “A workout starts with finding time, space and motivation. MoveRealm
   turns the room already around you into the controller.”
2. **Observe, 25 seconds:** choose three minutes and energy, capture one still, then call out that
   live video never leaves the browser.
3. **Constrain, 25 seconds:** show the obstacle pin and narrow side-step choice. Confirm the floor.
4. **Plan, 20 seconds:** show the live CodeBuddy badge and the three allowed rainforest mechanics.
5. **Calibrate, 15 seconds:** T-pose and one comfortable side-step establish actual camera framing.
6. **Play, 45 seconds:** reach for near targets; deliberately miss wide targets. Briefly step out of
   frame to demonstrate that low confidence pauses rather than guessing.
7. **Re-plan, 30 seconds:** choose “Too hard.” Read the trace aloud: missed targets caused a smaller
   envelope and slower tempo. Point to the before/after parameters.
8. **Result, 20 seconds:** show the garden postcard, active time, completion and measured FPS.
9. **Architecture + business, 25 seconds:** local MediaPipe signal path, typed CodeBuddy boundary,
   consumer product with corporate wellness/hospitality/community-fitness licensing potential.

## Backup path

Choose “Try the guided demo.” It uses a pre-validated tight-room profile and keyboard controls. The
UI labels both the profile and any deterministic director decision, so the backup never impersonates
a live agent result.
